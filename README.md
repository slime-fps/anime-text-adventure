# Anime Text Adventure Game

## About the Project

This is a text-based adventure game I developed using Python as part of my Introduction to Scripting course at Southern New Hampshire University.

I've always enjoyed anime and video games, so I wanted to bring those interests into my first programming project. The game allows players to explore different rooms, interact with the game through text commands, and work toward defeating a final boss named Kuro.

## Features

- Room navigation using text-based commands
- Interactive player input
- Room connections managed using Python dictionaries
- Game logic built with loops and conditional statements
- Anime-inspired story and setting

## Technologies Used

- Python 3
- Python dictionaries
- While loops
- Conditional statements
- User input handling

## How to Run

1. Install Python 3 on your computer.
2. Download the Python game file from this repository.
3. Open the file in a Python-compatible IDE or terminal.
4. Run the program.
5. Follow the instructions displayed in the terminal to play.

## What I Learned

Developing this game helped me better understand Python fundamentals, especially how dictionaries, loops, and conditional statements work together.

One of the biggest things I learned was how important debugging is. Getting the game to recognize commands and move between rooms correctly took some trial and error, but figuring out those problems helped me become more comfortable with programming.
